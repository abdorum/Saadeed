# سَدِيد — مُراجِعُ ما قبلَ النَّشرِ للمحتوى الدعوي

> ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا اتَّقُوا اللَّهَ وَقُولُوا قَوْلًا سَدِيدًا﴾ [الأحزاب: ٧٠]

**سديد لا يكتب عنك؛ سديد يريك ما قد لا تراه.**

مدققات الاقتباس تفحص ما بين القوسين، **وسديد يفحص الخطبة كلها:**
- الآية والحديث.
- والإجماع المدّعى، والقول المنسوب، والرقم، والتعميم.
- والفتوى التي لا يجيب عنها بل يحيلها.

ثم يرتّب ما وجده بثمن الخطأ، **والدليل من المصدر بجانب كل ملاحظة.**

مشاركة في «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026»، المسار الرابع: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

**الرابط الحي:** *يُضاف عند النشر.* · **الإصدار:** 0.3.0 ([سجل الإصدارات](CHANGELOG.md))

## ما يكشفه سديد

| في المسودة | ماذا يقول سديد |
|---|---|
| آية تبدّلت فيها كلمة | «يخالف المصدر»، والفرق كلمة بكلمة بجانب نص المصحف |
| آية نُسبت إلى النبي ﷺ، أو آيتان مدموجتان | يسمّي الموضع أو الموضعين، ويقترح النسبة الصحيحة |
| حديث في الصحيحين | «مؤيَّد بالمصدر»، والنص من المخزن |
| حديث في السنن الأربع | «وُجد دون حكم»: **«وُجد» لا تعني «صحّ»**، ومعه رابط الدرر |
| حديث لم يُعثر عليه | «لم يُعثر عليه في مصادر سديد»: **لا تعني «لا يصح»** |
| حديث مشتهر لا يصح | الحكم منقول بلفظ مصدره ونسبته، **ومعه البديل الثابت في معناه** |
| «أجمع العلماء…»، و«قال ابن القيم…» بلا مصدر، و«90% من الشباب…» | «يحسن توثيقه»، ومع التعميم والإجماع **اقتراح صياغة موسوم «مولَّد»** |
| فتوى لحالة شخصية، أو حكم على جماعة | **إحالة إلى مختص**: سديد لا يفتي |

ومع ذلك **خريطة المسودة:** كل جملة بصنفها (آية، حديث، أثر، قول عالم، دعاء، قصة، وعظ…).

## جرّبه

```bash
uv sync                        # Python 3.12
uv run saadeed data build      # تنزيل المصادر وبناء الفهارس (مرة واحدة)
uv run saadeed serve           # الواجهة والواجهة البرمجية: http://127.0.0.1:8000
uv run saadeed review samples/alukah_hifz_allisan.txt   # خطبة منشورة حقيقية
uv run saadeed review samples/demo_khutbah.txt --provider none   # بلا نموذج: المسار الحتمي وحده
```

- **مفتاح النموذج** في `.env`: `GEMINI_API_KEY=…` (الافتراضي `gemini-3.5-flash-lite`)، أو `SAADEED_LLM_PROVIDER=groq` مع `GROQ_API_KEY`.
- **وبلا مفتاح** تعمل المطابقة الحتمية للآيات والأحاديث المعلَّمة، ويقول التقرير بصراحة ما لم يُفحص.
- **الواجهة البرمجية:** `POST /v1/reviews`، وتوثيقها التفاعلي على `/v1/docs`.

## كيف يعمل

```
المسودة ← التقطيع ← الاستخراج (النموذج + المرور الحتمي) ← الفحص المتقاطع (كل ادعاء على المصحف)
        ← المتحققات (الآيات حتمية · الأحاديث: المشتهر، والمطابقة، ثم حَكَم يختار من مرشحين من المخزن)
        ← ميزان السداد (23 قاعدة) والقوالب ← حارس الإسناد ← التقرير
```

| يفعله الذكاء الاصطناعي | ويحرسه |
|---|---|
| استخراج الادعاءات، حتى غير المقتبس، وتصنيف كل جملة | **الفحص المتقاطع:** كل ادعاء يُعرض على فهرس المصحف أيًّا كان تصنيفه. والاقتباس غير الموجود في المسودة يُسقط |
| المطابقة بالمعنى بين حديث المسودة وخمسة مرشحين | **حارس الإسناد:** معرّفات من المخزن فقط، والنص يُجلب منه |
| اقتراح صياغة للتعميم والإجماع | **حارس الاقتراح:** لا آية، ولا حديث، ولا نسبة، ولا رقم جديد |
| **ولا يفعل أبدًا:** الحكم، والأثر، والإجراء، ونص الشرح | **جدول قواعد حتمي وقوالب**، يراجعها مختص |

- **المعمارية سداسية** (منافذ ومحوّلات)، وحدودها مفروضة بأداة `import-linter`. و**النتيجة نفسها في كل مرة:** القواعد حتمية، ونداءات النموذج مسجّلة.
- **التفصيل:** [المعمارية](docs/planning/04-architecture.md)، و[المتطلبات وجدول ميزان السداد](docs/planning/03-requirements.md)، و[دليل التوسعة](EXTENDING.md).

## المصادر وحوكمتها

- **كل مصدر «وصلة» خلف منفذ ثابت، معرّفة في [`data/manifest.toml`](data/manifest.toml)** بدورها: نص معتمد، أو مصدر احتجاج، أو حكم منقول، أو موضع، أو إحالة.
  - فصل مصدر أو تغيير دوره سطر في الملف، لا في الكود.
  - وكل تقرير يحمل بصمة الملف.
- **المصحف:** [الموسوعة القرآنية](https://quranpedia.net)، المسمّاة في الحزمة العلمية للمسابقة (رواية حفص، موافق لطبعة مجمع الملك فهد).
  - **و[Tanzil](https://tanzil.net) وصلة بديلة.** طابقناهما آيةً آية: 6228 من 6236 متطابقة، والفروق معلنة.
- **الحديث:** الكتب الستة من [Open-Hadith-Data](https://github.com/mhashim6/Open-Hadith-Data) (ODbL):
  - الصحيحان **مصدر احتجاج**.
  - والسنن الأربع **مصدر موضع دون حكم**.
- **الأحكام** من قائمة «المشتهر الذي لا يصح»، منقولة بلفظ مصدرها، ويحمل كل بند اسم مراجعه.
- **الدرر السنية** روابط بحث يفتحها الإنسان، لا استدعاء آلي.
- **التراخيص:** [`data/SOURCES.md`](data/SOURCES.md).

## الحدود (بصراحة)
- **الأحاديث خارج الكتب الستة:** لا يحكم عليها سديد. يحيل إلى الدرر، و«لم يُعثر عليه» ليست «لا يصح».
- **القول المنسوب لعالم، والإجماع، والرقم:** يُنبَّه عليها للتوثيق، ولا يملك سديد مصدرًا يتحقق به منها.
- **ما يقدّره النموذج:** الاستخراج ومستوى المحتوى والمطابقة بالمعنى. وكلها مقيسة، وقد تتباين بين نداءين جديدين.
- **العربية وحدها** في هذا الإصدار.
- **ما ينتظر الاعتماد البشري:** قائمة المشتهر، والحالات المصوغة يدويًا.

## الإفصاح
- **الإفصاح عن المنتج:** سديد أداة مراجعة مدعومة بالذكاء الاصطناعي، وليست فتوى. وعدم التنبيه على شيء لا يعني صحته.
- **عن البناء:** وثائق التخطيط سابقة على الكود. والكود كله من 4 أكتوبر 2026، وأول commit له موسوم `v0-start`. واستُعمل Claude (Anthropic) مساعدًا في البرمجة والتوثيق، بمراجعة المشارك.
- **عن البيانات:** لا تُخزَّن المسودات ولا تُسجَّل نصوصها.
