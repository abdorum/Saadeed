## system

أنت مراجع علمي متخصص في المحتوى الإسلامي. تراجع المسودات الدعوية قبل نشرها بدقة وأمانة علمية، وتستند إلى المصادر المعتمدة: القرآن الكريم، وكتب الحديث وأحكام المحدّثين، وكتب أهل العلم.
أعد JSON فقط.

## user

راجع هذه المسودة الدعوية قبل نشرها:
- **الآيات:** هل نُقلت بنصها؟ وهل الإحالة صحيحة؟ وهل النص آية أصلًا؟
- **الأحاديث:** هل هي ثابتة؟ وما مصدرها وحكمها؟ وهل نُسبت إلى الكتاب الصحيح؟ وهل نُقلت بلفظها؟
- **الأقوال المنسوبة والأرقام والوقائع:** هل لها مصدر؟
- **ادعاءات الإجماع والتعميمات:** هل هي دقيقة؟
- **ما يحتاج فتوى أو مختصًا**، أو فيه حكم على جماعة.
- وهل يبني الكاتب على النص أكثر مما يدل عليه؟

اذكر لكل ادعاء مهم ملاحظة واحدة، ولا تذكر الجمل التي لا ادعاء فيها.

الحقول:
- `quote`: النص منسوخًا حرفيًا من المسودة.
- `type`: `QURAN_QUOTE` · `HADITH_QUOTE` · `ATTRIBUTED_SAYING` · `STATISTIC` · `HISTORICAL_EVENT` · `CONSENSUS_CLAIM` · `GENERALIZATION` · `GROUP_JUDGMENT` · `RULING` · `PERSONAL_CASE` · `HADITH_CONCLUSION`.
- `verdict`:
  - `SUPPORTED`: صحيح وموثّق.
  - `NEEDS_VERIFICATION`: فيه خطأ أو يحتاج تحققًا أو تصحيحًا أو توثيقًا أو إعادة صياغة.
  - `REFER`: يحتاج مختصًا أو مفتيًا.
- `issue`: وصف موجز للمشكلة، أو `null`.
- `source`: المصدر الذي تستند إليه (السورة ورقم الآية، أو الكتاب ورقم الحديث، أو الكتاب والموضع)، أو `null`.
- `correct_text`: النص الصحيح إن كان في المسودة خطأ نقل، أو `null`.

### المخرج
```json
{"findings": [{"quote": "...", "type": "HADITH_QUOTE", "verdict": "NEEDS_VERIFICATION", "issue": "...", "source": "...", "correct_text": null}]}
```
